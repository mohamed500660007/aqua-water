# Aqua Water — لوحة تحكم إدارة المبيعات والمخزون

لوحة تحكم داخلية لشركة أكوا ووتر (فلاتر مياه) مبنية بـ Laravel 12 + Blade + Alpine.js،
بواجهة عربية (RTL) بالكامل، وكل الوحدات تعمل على قاعدة بيانات حقيقية (بدون بيانات وهمية).

## الوحدات

| الوحدة | الوصف |
|---|---|
| عقود البيع | عقود نقدية أو بالتقسيط، بنود مرتبطة بالمخزون، ربط بخطة صيانة، حساب أقساط تلقائي |
| العملاء | بيانات العميل، أرقام هاتف متعددة مع تحديد الأساسي |
| المنتجات | كتالوج المنتجات وأسعارها |
| المخزون | أرصدة المخزن الرئيسي، سجل الحركات (وارد/منصرف/تسوية)، ومخزون كل موظف |
| خطط الصيانة | خطط بها بنود منتجات ودورية استبدال، تُنسخ داخل العقد وقت التعاقد |
| الموظفون | حسابات مندوبي المبيعات وفنيي التركيب وباقي فريق العمل |

راجع [ARCHITECTURE.md](ARCHITECTURE.md) لتفاصيل البنية والطبقات.

## المتطلبات

- PHP 8.2+
- Composer
- Node.js (لأصول الواجهة عبر Vite)

## التشغيل محليًا

```bash
composer install
cp .env.example .env
php artisan key:generate

touch database/database.sqlite
php artisan migrate --seed

npm install
composer dev
```

`composer dev` يشغّل الخادم + قائمة الانتظار + السجلات + Vite معًا. التطبيق بعدها على `http://localhost:8000`.

## سير العمل على Git

المشروع يتبع نموذج **Git Flow**:

- `main` — الإصدارات الجاهزة فقط.
- `develop` — فرع التكامل، كل الميزات المُنجزة تُدمج هنا أولًا.
- `feature/<name>` — كل ميزة جديدة تُبنى في فرعها الخاص المتفرّع من `develop`، وتُدمج فيه بـ `--no-ff` عند الانتهاء.

```bash
git checkout develop
git checkout -b feature/my-feature
# ... العمل على الميزة ...
git checkout develop
git merge --no-ff feature/my-feature
```

عند جاهزية `develop` للإصدار، تُدمج في `main`.
